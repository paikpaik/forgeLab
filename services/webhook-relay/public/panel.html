localhost:3401/channel.html

둘러보기

  1. 엔드포인트 추가 — "+ 새 엔드포인트"로 등록하면 곧바로 목록에 나타나고, 상태는 정상으로 시작합니다.
  2. 테스트 이벤트 보내기 — 각 엔드포인트 옆 버튼으로 그 이벤트 타입을 구독 중인 엔드포인트 전체에 이벤트를 전달합니다. 몇 초 안에 상태가 갱신되고, "정상 응답"/"느린 응답" 엔드포인트로 실제 도착하면 아래 "실시간 알림 채널"에 메시지로 나타납니다(트랜잭션 아웃박스 발행 주기 때문에 즉시는 아닙니다).
  3. 장애 상황 재현 — 등록 시 "장애 시뮬레이션"을 고르고 이벤트를 여러 번 보내면, 연속 실패 임계치를 넘는 순간 상태가 일시 중단으로 바뀌고 이후 요청은 실제 호출 없이 즉시 보류됩니다. 여러 delivery-worker 인스턴스로 스케일해도(docker compose up -d --scale delivery-worker=2) 이 상태는 Redis로 공유됩니다.
  4. 개발자 콘솔 — 우측 하단 버튼을 누르면 실제 브라우저 개발자 도구처럼 "로그"와 "엔드포인트 상태"(circuit 원시값 + 배달 이력 + dead 복구) 탭을 확인할 수 있습니다. 상단 손잡이를 드래그하면 높이 조절이 가능합니다. 지표는 /metrics에서 확인하세요.
