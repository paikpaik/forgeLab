주문(order-service)과 재고 예약(inventory-service, 2개 인스턴스)을 gRPC로 순차 호출하는 orchestration saga입니다. "영수증 보기"에서 진행 상태를 실시간으로 볼 수 있습니다.

내 주문 내역

둘러보기

  1. 해피 패스 — 로그인 후 widget-plenty로 체크아웃하면 ORDER_TRIED → INVENTORY_TRIED → CONFIRMED 순서로 몇 초 안에 전이됩니다.
  2. 영수증 — "영수증 보기"를 누르면 이 saga가 실제로 도달하는 곳 (결제 완료 영수증/주문확인 페이지)을 별도 창으로 볼 수 있습니다.
  3. 보상 트랜잭션 — widget-scarce 재고가 0이면 order Try는 성공하지만 inventory Try가 실패해서 COMPENSATING → CANCELLED로 갑니다.
  4. 테스트 도구 — 우측 상단에서 admin 로그인, 재고 강제 리셋, 인가 실패 재현, 다중 인스턴스 경쟁 테스트(동시 체크아웃 2건)를 실행할 수 있습니다.
  5. 개발자 콘솔 — 우측 하단 버튼에서 실시간 로그(체크아웃 시작/재고 리셋)와 재고/saga 원시 상태를 확인할 수 있습니다. 각 프로세스의 /health, /metrics는 gateway :3300/health, orchestrator :3301/health, order-service :3302/health에서 확인 가능합니다(inventory-service는 2인스턴스라 호스트 포트를 노출하지 않습니다).
