입찰 이력

둘러보기

  1. 입찰 — 경매를 고르고 최소 증분 이상으로 입찰하면 즉시 반영되고, 다른 사람이 입찰하는 것도 WebSocket으로 실시간으로 보입니다.
  2. 관전자 화면 — "🎥 관전자 화면으로 보기"를 누르면 이 경매가 실제로 중계되는 곳(전광판/방송 화면 스타일)을 별도 창으로 볼 수 있습니다.
  3. 다중 인스턴스 동기화 — 이 서비스는 처음부터 다중 인스턴스 전제로 만들어졌습니다. docker compose up -d --scale app=3으로 스케일하면 3500/3501/3502 중 다른 포트로 접속해도 입찰이 실시간으로 똑같이 보입니다(Redis pub/sub로 인스턴스 간에 방송됨).
  4. 동시 입찰 경쟁 — 우측 상단 "테스트 도구"에서 "동시 입찰 2건 발사"를 누르면 높은 값/낮은 값을 거의 동시에 보내서, 순서와 무관하게 항상 더 높은 금액이 최종 상태로 수렴하는지(Redis 분산 락) 확인할 수 있습니다.
  5. 개발자 콘솔 — 우측 하단 버튼에서 실시간 로그와 Redis 원시 상태를 확인할 수 있습니다. 지표는 /metrics에서 확인하세요.
