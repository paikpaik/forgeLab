테스트 방법

  1. 지연 확인 — "참가하기" 후 "+10점 올리기"를 누르면 즉시 이벤트 로그에 "발행함"이 찍히지만, 전체 랭킹에 실제로 반영되는 건 Kafka consumer가 이벤트를 소비한 다음입니다(보통 1초 안쪽). 이 발행-반영 사이의 시간차가 이 실험의 핵심입니다.
  2. 이벤트 시뮬레이션 — "한번에 발사"를 누르면 8명의 봇에게 무작위 점수 이벤트가 쏟아지고, 랭킹이 실시간으로 뒤바뀌는 걸 볼 수 있습니다.
  3. 멱등성 확인 — 브라우저 콘솔에서 같은 eventId로 /leaderboards/default/events를 두 번 POST 해보세요. 점수가 두 번 반영되지 않고 한 번만 반영되는 걸 확인할 수 있습니다(Redis 기반 멱등성 저장소).
  4. 초기화 — 테스트를 반복하고 싶으면 "초기화" 버튼으로 랭킹을 전부 지우고 처음부터 다시 시작할 수 있습니다.
  5. 관측 지표 — aggregator의 /metrics(반영/중복 카운터), /metrics/kafka(consumer lag, DLQ 이동 수)에서 직접 확인할 수 있습니다.
