행을 클릭하면 시도 이력(재시도/회로차단/거래조회 등)이 펼쳐집니다.

둘러보기

  1. 결제 요청 — 금액과 연동 버전(v1/v2)을 골라 요청을 보내면, 내부적으로 ForgeHttpClient가 fake-pg(외부 결제대행사 흉내)를 호출합니다.
  2. 상태 — 승인 / 실패 / 응답 미수신(거래조회 대기 중) / 거래조회 포기(운영자 확인 필요)로 나뉩니다.
  3. 테스트 도구에서 fake-pg의 실패율/타임아웃율/비동기율을 조절해서 재시도·서킷브레이커· IN_DOUBT→거래조회 해소 과정을 직접 재현해볼 수 있습니다.
  4. 쇼핑몰 결제창 — 우측 상단 링크로 실제 소비자가 보는 결제 화면(별도 페이지)을 열어볼 수 있습니다. 회로가 열려 있으면 실패 사유 대신 "일시적으로 지연되고 있습니다" 문구가 보입니다.
  5. 개발자 콘솔 — 우측 하단 버튼에서 실시간 로그를 확인하세요. 지표는 /metrics에서 확인 가능합니다.
