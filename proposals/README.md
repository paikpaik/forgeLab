# proposals — forge 패키지 확장/수정 제안서

`node-forge`/`kafka-forge`에 부족하거나 확장이 필요한 기능이 실험 중 발견되면, 소스를 직접 고치지 않고 여기에 제안서를 남긴다. 반영/배포는 사용자가 각 forge 레포로 가져가서 진행한다.

## 구조

```
proposals/
├── node-forge/<YYYYMMDD>-<주제>.md
└── kafka-forge/<YYYYMMDD>-<주제>.md
```

## 제안서에 포함할 내용

- **계기**: `services/` 아래 어떤 실험에서 어떤 니즈가 생겼는지
- **현재 한계**: 지금 forge 패키지로 안 되는 이유 (우회 방법이 있다면 그것도)
- **제안**: 추가/변경하려는 API·모듈의 형태 (시그니처 수준)
- **기각한 대안**: 검토했지만 채택하지 않은 방법과 이유
